# Burp Suite 웹 보안 실습

브라우저가 보낸 요청을 Burp Suite에서 확인,수정하고, Java서버에서 검사,방어하는 순서로 실습한 자료입니다

##실습 순서

1. Burp Suite 설치
2. Burp Suite 전용 브라우저 열기
3. Java POST 서버 접속
4. 로그인 요청 가로채기
5. POST 데이터 확인
6. 연습용 입력값 확인
7. 변경한 요청을 Java서버로 전송
8. Java 서버의 입력값 검증 확인
9. XSS 실습과 방어
10. 쿠키와 세션 확인
11. 반복 로그인 공격 방어
12. 파일 업로드 보안
